# Design and Analysis of Algorithms
## Assignment 1

This project implements the MergeSort, QuickSort, and QuickSelect algorithms. The code is strictly organized into packages, tested using JUnit 5, and includes a benchmarking system for analyzing asymptotic complexity.
## How to launch

1. **Running tests:** Open the `AlgorithmsTest` class in the `src/test/` folder and run it.
2. **Benchmarking:** Run `Main.java`. The program will process arrays of up to 1,000,000 elements and generate a `results.csv` file.
